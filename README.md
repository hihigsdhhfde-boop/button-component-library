## 🚀 How to Use

1. **Open** `index.html` in your browser
2. **Click** any button to trigger its action
3. **Watch** the stats update in real-time:
   - **Health**: Your current HP
   - **Inventory**: Current weapon/item
   - **Zombies**: Number of spawned enemies
   - **Gold**: Currency collected

## 🎮 Game Mechanics

### 💓 Health System
- Start with 100 HP
- Take damage from various sources
- Heal with healing buttons
- Death occurs at 0 HP
- Game automatically detects when you're dead

### 🛡️ Armor System
- Equip armor to reduce incoming damage by 50%
- Only one armor type active at a time
- Armor persists until replaced

### ⚔️ Weapon System
- Collect various weapons
- Affects battle strategies
- Display current weapon in inventory
- Weapons don't disappear after use

### ⚡ Power-ups
- Activate temporary buffs
- Last 10 seconds each
- Can stack multiple power-ups
- Auto-deactivate after duration
- Visual confirmation of activation/deactivation

### 💰 Gold Currency
- Earn from battles
- Direct gold additions available
- Used for game progression
- Accumulates over time

### 💀 Status Effects
- Apply negative effects to yourself
- Deal damage over time
- Auto-remove after 8 seconds
- Visual message confirmation

### 🎯 Combo System
- Increases with Frenzy Mode
- Tracks gameplay performance
- Can be used for future multipliers

## 🎯 Game Flow

1. **Equip Armor** → Reduces incoming damage
2. **Get Weapons** → Prepare for battle
3. **Spawn Enemies** → Create challenges or start battles
4. **Engage in Combat** → Take damage and use spells
5. **Heal** → Recover health
6. **Earn Gold** → Accumulate currency
7. **Activate Power-ups** → Boost your stats
8. **View Stats** → Track your progress
9. **Reset** → Start a new game
